# FirstWord AI
### A little friend. A world of words.

A working, Bangla-first, local-first competition MVP. A child can talk or type to **Mithu (মিঠু)**, an original animated pet, and change an actual illustrated world. React + TypeScript frontend, Express backend, validated world engine, consent-controlled local persistence, and optional entirely local speech/model integrations.

**No paid API, account, trial credits, subscription, hosted database, or cloud inference service is required.**

## What works now

- Original SVG pet with idle, listening, thinking, speaking, happy, curious, confused, worried, celebrating, and comforting visual states. The main interaction uses relevant states; not every available expression has a distinct gameplay trigger.
- Real stateful scenes: **Help My Pet**, **Restaurant / Shopping**, and **Create Your Own World**. Additional moon, stage, and pretend care-room scenes are intentionally simpler.
- Places, roles, characters, objects, colors, movement, safe story events, activity changes, one-step undo, and rest. Characters/objects continue across scene changes; a story reset clears them.
- Bangla and English text instructions, plus real microphone recording when enabled. English is an interface aid; pet replies remain Bangla.
- Actual local Whisper transcription and eSpeak NG Bengali audio output when installed. Stop recording, cancel, replay, mute auto voice, and immediately stop audio.
- Bangla transcripts are shown for confirmation/editing before submission. English-mode transcripts continue automatically. Edited transcripts are labelled text input, not unmodified speech recognition.
- Rules-based adaptation from real word usage, short replies, storytelling interest, and interaction patterns. A recommended activity actually launches the selected scene.
- Parent area with actual observed vocabulary/skill counts, seven-day interaction chart, recent history, nickname, storage/microphone controls, JSON export, and deletion.
- Isolated, resettable presenter demo using explicitly labelled **text inputs + deterministic rules**. Its data does not pollute the regular profile.

## Honest capability status

| Capability | Current implementation / verified status |
|---|---|
| World and conversation | Live backend state changes; deterministic bilingual intent rules and state-dependent Bangla reply templates |
| Generative intent interpretation | Optional local Ollama adapter, schema-validated; **no LLM was installed/run in this workspace**. Adapter contracts were tested with mocks, not live inference |
| Microphone capture | Real `getUserMedia` + `MediaRecorder`; tested in Chromium with a **synthetic microphone audio fixture** |
| Speech recognition | Local faster-whisper `tiny`, CPU INT8. English synthetic test transcribed correctly |
| Bangla recognition | **Experimental and unreliable in testing.** Both tiny and base misrecognized an eSpeak-generated Bangla sample. This is not a validation on real adults or children |
| Bangla speech output | Real eSpeak NG `bn` synthesis; WAV generation and browser playback verified. Robotic voice, not natural-quality speech |
| AI responses | Safe templates even when Ollama interprets intent; not unrestricted generative dialogue |
| Pronunciation / diagnosis | Not implemented. No pronunciation scores, developmental ages, clinical estimates, or diagnoses |
| Demo mode | Labelled text sequence, real state/progress changes, offline rules. Optional replay still produces real eSpeak audio |

The interface displays provider availability, labels rules mode, and shows the mode used for each turn. **An available Ollama model is not the same as successful inference**: failures/timeouts/invalid actions fall back to rules with a visible note. Voice errors never create hardcoded transcriptions.

## Quick start — core app, no models required

Tested on Debian 13, Node **20.20.2**, npm 10, Python **3.13**. Use Node 20.19+ (or a compatible newer LTS).

```bash
cd firstword
npm ci
npm run dev
```

Open **http://localhost:3000**. The server binds to `0.0.0.0` for live previews. Frontend API calls use relative `/api` URLs; no browser code points to a separate localhost service.

Type this into the field below the microphone:

```text
একটি বেগুনি প্রাসাদ বানাও, বন্ধু ড্রাগন আনো, আমি রাজা হব
```

Then:

```text
ড্রাগন আম খেতে চায়
চলো রেস্তোরাঁ খুলি
আমি দোকানদার হব
ভাত
মাছ
```

All of these work without Python, a language model, internet, or speech hardware. Unknown requests receive a clarification rather than a fabricated scene.

For a production-style local demo:

```bash
npm run build
npm start
```

These commands use a POSIX shell (Linux/macOS/WSL). Backend changes need a server restart; Vite hot-reloads frontend changes. `dist/` is generated by the build and is not needed in the source archive.

## Enable real local speech

### 1. Bengali speech output

Debian/Ubuntu/WSL:

```bash
sudo apt-get update
sudo apt-get install espeak-ng
espeak-ng --voices=bn
```

The last command must list **Bengali**. eSpeak NG must be on `PATH` when starting the Node app. The backend spawns the executable with fixed arguments and writes text to stdin—never interpolates a shell command. It streams generated WAV bytes without saving audio files.

On other systems, install eSpeak NG using its official distribution. If absent, the app attempts only a browser voice reporting `localService` and the matching language. It does not assume Bengali is installed and does not opt into a browser cloud voice.

### 2. Local Whisper transcription

In a separate terminal, inside the project:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r speech/requirements.txt
python -m uvicorn speech.server:app --host 127.0.0.1 --port 8001
```

First startup downloads public multilingual Whisper `tiny` weights into `~/.cache/firstword-whisper`. No token, account, or credit card is needed. It needs internet **once** for the weights. Downloaded model weights are intentionally not bundled in the source archive.

For subsequent offline starts:

```bash
WHISPER_OFFLINE=1 python -m uvicorn speech.server:app --host 127.0.0.1 --port 8001
```

A model must already be cached; otherwise offline startup fails honestly. The core app still works.

The dependency pin **`av==15.1.0` is important**: installed PyAV 19 was incompatible with faster-whisper 1.2.1's decoding call during testing. The pinned combination was tested on Python 3.13.

Optional different model on a more capable machine:

```bash
WHISPER_MODEL=small python -m uvicorn speech.server:app --host 127.0.0.1 --port 8001
```

`small` has **not** been benchmarked here; allow substantially more memory and latency. We also evaluated `base`, which did not fix the synthetic Bangla sample. Do not assume a larger model guarantees child Bangla accuracy.

### 3. Use the microphone

1. Open the application via localhost or HTTPS. In a hosted preview, open it in a full browser tab if the embedding frame blocks microphone access.
2. Click the microphone. A guardian must explicitly allow audio processing and local transcript/progress storage.
3. Grant the browser microphone permission.
4. Click the microphone again to start; tap the square to finish. Recording stops automatically after 30 seconds.
5. Bangla transcripts require confirmation via the send button and can be edited first. Unedited recognition remains labelled Whisper audio; corrected text is labelled text input.
6. Use **EN** for English audio. English recognition was the reliable synthetic smoke-test path; Mithu still answers in Bangla.
7. Replay using the speaker button; stop immediately with the audio stop button or mute auto voice.

Provider health is cached for up to 10 seconds. The Help dialog has a refresh button. Empty speech, denied permission, unsupported browsers, failed decoding, and unavailable services have text/retry paths. A Bangla-mode result containing no Bengali script is rejected instead of pretending it is reliable; this is a **script sanity check**, not a confidence or pronunciation score.

## Optional: enable local generative intent interpretation

Install the **local Ollama runtime** from its official project. No Ollama account or cloud model is needed.

```bash
ollama serve
# In a second terminal:
ollama pull qwen2.5:1.5b
```

Start/restart FirstWord normally. The backend checks `http://127.0.0.1:11434` and only uses the configured model when it is present. It includes structured world state and the last four instructions in the model context.

The model returns only validated JSON actions. Unsupported actions, extra properties, unknown values, more than ten actions, invalid JSON, or timeouts are rejected. The fallback uses the original request, not the rejected proposal. Model prose is never rendered or executed.

For a smaller local model (quality, especially Bangla, may be worse):

```bash
ollama pull qwen2.5:0.5b
OLLAMA_MODEL=qwen2.5:0.5b npm run dev
```

`qwen2.5:1.5b` is about 986 MB for the listed quantized weights; runtime memory is higher. Use sufficient RAM and test warm latency before judging. This roughly 2 GB sandbox was kept focused on the real speech path and reliable fallback; **live Ollama inference is unverified here**. The adapter times out after 18 seconds and remains usable via rules.

Only loopback provider URLs are accepted:

| Variable | Default |
|---|---|
| `PORT` | `3000` |
| `OLLAMA_URL` | `http://127.0.0.1:11434` |
| `OLLAMA_MODEL` | `qwen2.5:1.5b` |
| `WHISPER_URL` | `http://127.0.0.1:8001` |
| `WHISPER_MODEL` (Python) | `tiny` |
| `WHISPER_CACHE` (Python) | `~/.cache/firstword-whisper` |
| `WHISPER_OFFLINE` (Python) | `0`; set `1` after caching |

Do not configure cloud-backed model variants. There are no API-key settings or mandatory remote inference services.

## Privacy, storage, and scope

- Without consent, the current profile exists only in server memory; no profile file is created. It survives page reload within the current server process, not a server restart.
- Consent enables transcript/progress persistence in **`data/<random-browser-capability>.json`**. Files are local, plaintext, and created with owner-only permissions where supported. An HttpOnly, SameSite cookie separates browser profiles.
- One child profile per browser session is supported. Use separate browser profiles/contexts for separate children; there is no multi-child account switcher yet. Demo data is separate and memory-only.
- Audio exists in transient browser/server memory only. The speech worker may buffer uploaded multipart data through its framework; under normal 30-second compressed recordings it remains in memory. Do not upload huge external files or treat framework buffering as forensic secure erasure.
- **Hosted preview is not your own laptop**: audio/transcripts travel to the preview server. Run the app on your own computer for a genuinely local venue demo. Local model/speech tools do not forward data to cloud inference providers.
- Turning storage consent off deletes the persisted file and disables microphone permission, while keeping a temporary current session in memory. **Delete all data** clears history, world, vocabulary, observations, consent, microphone permission, and the profile file.
- Entering the parent area, cancelling recording, revoking microphone permission, deleting data, or navigating away releases microphone tracks and cancels playback. A submitted recognition request may finish inference on the local worker, but revoked results are rejected.
- At most 200 conversation turns and 100 completed-activity records are retained. Vocabulary/skill occurrence counts are cumulative. Charts show retained turn observations—not speech quality or developmental progress.
- No ads, analytics, third-party fonts, public chat, real diagnosis, or punishment for silence.
- Strict action schemas, bounded input, fixed model destinations, same-site request checks, and safe rendering are useful MVP safeguards, **not production child-safety, medical, or legal compliance**. The content filter is intentionally basic and can miss unsafe language. Do not deploy as a public multi-user children's service without further safeguards.

## Project structure

```text
src/
  App.tsx                    Navigation, conversation UI, demo, consent
  speech.ts                  Real microphone lifecycle, replay, cancellation
  components/Pet.tsx         Original animated SVG character / expressions
  components/World.tsx       Stateful scene + object / character renderer
  components/Dashboard.tsx   Parent observations, controls, history, export
  styles.css                 Responsive design, animation, reduced-motion support
shared/engine.ts             Action schemas, world reducer, intent rules, adaptation
server/
  index.ts                   Express APIs, isolated sessions, local persistence
  providers.ts               Loopback Ollama / Whisper and eSpeak adapters
speech/
  server.py                  Local CPU Whisper worker, Bengali script sanity check
  requirements.txt           Tested Python dependency pins
public/fonts/                Bundled Noto fonts and license notices
 tests/                     Engine, provider-contract, browser, audio-path tests
 docs/                      Demo guide, test report, architecture, free-tool sources
 artifacts/                 Synthetic audio fixtures and test evidence
```

To add a supported object: extend the Zod enum, bilingual rules and label in `shared/engine.ts`, add its SVG in `ObjectArt`, update the Ollama action vocabulary, then add a test. Never bypass action validation to make a model request appear to work.

## Free dependencies / services

All artwork was drawn in code for this project; no asset-generation service was used. Runtime libraries are React, Express, Zod and Lucide. Development uses Vite, TypeScript, tsx, ESLint, Prettier, Vitest and Playwright. Speech uses faster-whisper/CTranslate2/PyAV/ONNX Runtime, FastAPI/Uvicorn, and eSpeak NG; optional models use Ollama + Qwen. Noto fonts are bundled. **No external inference/database/hosting service is mandatory.** Package and model downloads need internet during installation only.

Licenses and official source links: **[docs/FREE_TOOLS.md](docs/FREE_TOOLS.md)**. Dependency/model licenses remain their own; this project's original code and artwork use the included MIT license.
